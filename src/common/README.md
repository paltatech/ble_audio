# common/

Shared types, macros, error codes, and stateless utility helpers used across
every layer.

**Dependency rule:** code here must not depend on `core/`, `middlewares/`,
or `application/` — only on Zephyr and the C standard library. Keeping it
dependency-free means it can be unit tested under `native_sim` without
pulling in any hardware.

Add new files flat in this folder (no `Inc`/`Src` split); if a header-only
utility grows source files, wire them into [CMakeLists.txt](CMakeLists.txt).

Currently contains `app_version.c/.h` — reads the build-time version macros
generated by [tools/cmake/version.cmake](../../tools/cmake/version.cmake)
into `app_build_version.h` and prints/exposes the firmware version at boot.
It qualifies for `common/` because it has no dependency on any other layer.
