# docs/

Design notes, architecture decisions, and test reports for this project.

This project is the working example for the Zephyr testing ecosystem
progression described in
[zephyr_testing_ecosystem.md](zephyr_testing_ecosystem.md).
[testing_ecosystem.md](testing_ecosystem.md) tracks the implementation of
that progression in this repo: status per priority, what was built, and
the reasoning/gotchas behind it. Keep it updated as each priority lands.

Further notes and reports can live here too (e.g. under `docs/reports/`,
following the convention used by sibling projects in this workspace).
